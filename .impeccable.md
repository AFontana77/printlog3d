# PrintLog3D — Impeccable Design Context

## Design Context

### Users
3D printing enthusiasts — makers, hobbyists, engineers who've been printing for at least a year and are frustrated by the lack of organized settings history. They're at their desk or workshop, tablet or phone nearby, dialing in a new filament brand or checking why their last print failed. They know the difference between PLA+ and PETG. They have opinions about bed adhesion.

### Brand Personality
Three words: **obsessive, technical, maker.**

Not startup-smooth. Not consumer-friendly. This is for people who have a drawer of failed filament samples labeled with masking tape. The site should feel like a well-organized lab notebook or a GitHub README for a tool you actually use. Zero fluff. Every number matters.

### Aesthetic Direction
**Light theme.** Workshop desk during the day — they're printing, they're looking at the screen, it's bright. Dark would feel wrong in a maker context (that's for gamers, not engineers logging temps).

**Font pair:**
- Display: `Chakra Petch` — a semi-condensed geometric sans with a slight angular quality. Used in motorsport and engineering contexts. Reads like product spec sheets, PCB silkscreen, or a controller interface. NOT a monospace (the reflex for "technical" — rejected). Chakra Petch has a precision quality that matches someone who cares about nozzle temp to the degree.
- Body: `Fira Sans` — clean, readable, slightly technical without being aggressive. Wide character support, excellent at small sizes, pairs cleanly with Chakra Petch's angles. Not in the reflex list.

**Color system (OKLCH, light):**
- Background: `oklch(0.99 0.004 295)` — near-white with violet tint
- Surface/card: `oklch(0.96 0.008 295)` — light violet-tinted surface
- Surface2: `oklch(0.92 0.012 295)` — medium tint for alternating sections
- Foreground: `oklch(0.15 0.02 295)` — near-black with violet tint
- Muted foreground: `oklch(0.48 0.015 295)` — mid gray-violet
- Border: `oklch(0.84 0.015 295)` — subtle violet-tinted border
- Primary (violet): `oklch(0.43 0.22 295)` — strong violet, readable on light
- Primary dark: `oklch(0.34 0.20 295)` — hover/pressed
- Accent: `oklch(0.62 0.16 315)` — slightly warmer purple-violet for highlights

**Reference feel:** GitHub README pages, Prusa Knowledge Base, Bambu Lab print settings docs, engineering spec sheets. Anti-reference: Thingiverse (cluttered), MakerBot (consumer startup), any SaaS dashboard with gradient hero, any site that says "dial in your 3D printing journey."

### Design Principles
1. **Specs ARE the content.** "1,260°C × 1.75mm × 5 filament types" — technical parameters should be displayed with the visual weight they deserve.
2. **Left-aligned, grid-disciplined.** Not centered. Engineering references don't center their text. Left-aligned with a consistent column structure.
3. **Numbers in Chakra Petch at large scale.** The database count is the value proposition. Let it breathe at display size.
4. **No icon cards.** Features are displayed as a spec table or a clean row list with dividers, not a 2×2 card grid with Lucide icons.
5. **Tabular number styling.** Any numbers showing specs use `font-variant-numeric: tabular-nums` so columns align cleanly.

### Layout direction for homepage
- Hero: Left-aligned, one-column with large Chakra Petch display type. The subhead is tight and specific (temperatures, material types). Right side: a small "spec preview" panel showing sample filament data in a table format.
- Middle section: A horizontal strip with 3 large stat numbers (1,260 filaments, X brands, 6 material types) in Chakra Petch at large scale.
- Feature section: A clean spec-table-style list (name | description rows with dividers), NOT icon cards.
- CTA section: Violet-tinted panel. Technical language, no fluffy calls to action.
- Overall: Precise, data-forward, maker-grade.

### WCAG
Full WCAG 2.1 AA. `oklch(0.15 0.02 295)` on `oklch(0.99 0.004 295)` is approximately 13.5:1.
